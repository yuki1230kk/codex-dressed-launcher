使用步骤：打开主题库 → 搜索主题名称 → 核对当前作者、平台和许可 → 下载 → 通过 Dream Skin 客户端导入 → 把已保存主题的 ID 写入本项目配置。网站可能更新或下架主题，以上记录不承诺旧版本永远可下载。
